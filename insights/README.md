# @sessionsight/insights

Client-side session recording, heatmaps, funnels, and form analytics.

## Install

```bash
npm install @sessionsight/insights
```

Or via script tag:

```html
<script src="https://cdn.sessionsight.com/sessionsight.js"></script>
```

## Documentation

Install, configuration, API reference, and privacy controls: [sessionsight.com/docs/insights](https://sessionsight.com/docs/insights).
