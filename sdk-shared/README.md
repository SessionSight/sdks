# @sessionsight/sdk-shared

Shared utilities used by the SessionSight SDKs (insights, feedback, flags, goals, split-testing). PII redaction, stable element selectors, visitor-id handling, and request-shape helpers.

This package is installed as a transitive dependency of the user-facing SDKs. You typically won't import it directly.

## Documentation

See the [SessionSight docs](https://sessionsight.com/docs).
