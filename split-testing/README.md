# @sessionsight/split-testing

A/B and split testing with zero-flicker rendering and SSR bootstrap.

## Install

```bash
npm install @sessionsight/split-testing
```

Or via script tag:

```html
<script src="https://cdn.sessionsight.com/sessionsight-split-testing.js"></script>
```

## Documentation

Install, configuration, and API reference: [sessionsight.com/docs/split-testing](https://sessionsight.com/docs/split-testing).
